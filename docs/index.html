How it works

A neural network from scratch

The reflex agent is a Q-network written in plain NumPy: forward pass, hand-derived backpropagation, Huber loss and Adam, with gradients checked against finite differences. It sees the 11 inputs of the classic tutorial agent.

A full-board agent

A small convolutional Q-network reads the whole grid, rotated so the snake always faces up. The body is encoded in head-to-tail order as moves until this square clears, so the network can tell which walls are about to open.

A planner

Given a fixed budget of simulated moves, a beam search plays out legal futures with the real engine and ranks the frontier with the network's own value estimate. Slide the budget and watch its decisions change.

A proof engine

For any position, every continuation of a move is enumerated. A move is doomed only when all of them collide, and survives only when a concrete escape line exists. If the search runs out, it says so. A bad outcome alone never counts as proof of a bad move.

A puzzle generator

Thousands of positions are grouped by their 11-input observation. Pairs with identical observations but disjoint sets of surviving moves become two-board puzzles: a precise picture of the information the reflex agent is missing.

A deterministic replay engine

Food comes from a seeded 32-bit stream that is part of the game state, and the Python and JavaScript engines agree bit for bit. A seed and a list of moves reproduce any game exactly, so every position can be rewound, branched and shared as a link.
